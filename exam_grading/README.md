# exam_grading — 大学の筆記試験をAIで採点するための Claude Code スキル

手書き答案をスキャンして Claude（AI）で採点し、個人別に返却し、疑義申告に対応するまでの一連の工程を標準化した
**科目非依存**のスキルです。豊橋技術科学大学の学部専門科目（受講者130名超・年2回の試験）での実運用から作られています。

実績: 132名 × 25小問の期末試験を、**実施当日中に採点・個人別成績PDF返却まで完了**。

> ⚠️ 元になった科目の採点スキームがそのまま他科目に使える保証はありません。
> 本スキルが提供するのは**工程の骨格・原則・チェックリスト・スクリプト雛形**です。
> 配点・部分点・クロップ座標・返却手段は各科目で作り直してください。

---

## 何ができるか

```
作問設計 → 実施・スキャン → 画像化・表裏ペアリング → 本人特定OCR
        → 採点基準の明文化 → 並列AI採点 → 機械検証
        → ★教員確認（画像付きHTML） → 帳票・個人PDF生成 → 返却 → 疑義申告対応
```

このスキルの特徴は、**AIに全部任せない設計**になっていることです。

- AIが判読に迷った箇所・部分点の付け方を判断しかねた箇所は、**答案画像のキャプチャを埋め込んだHTML**にして
  教員に提示し、判定を仰ぐ工程が**必須**として組み込まれています（教員の作業は10〜20件のカードを数分見るだけ）。
- 点数を動かした理由がすべて記録に残るため、学生からの疑義申告に一貫した回答ができます。
- 学生による「採点AIへの指示」（プロンプトインジェクション）対策が標準で入っています（毎回実際に来ます）。

## インストール

Claude Code の個人スキルとして配置します。

```bash
git clone https://github.com/sayonari/exam-grading-skill.git ~/.claude/skills/exam_grading
```

または、既存のスキルフォルダに中身をコピーしてください。配置後、Claude Code に

> テストの採点をしたい

と伝えれば、Claude がこのスキルを参照して工程を進めます（`/exam_grading` で明示的に呼ぶこともできます）。

Python スクリプトを使う場合は `pillow`（必須）と `openpyxl`（Excel出力用）が必要です。

## まず読むべき3つ

1. **`SKILL.md` の「最初に読むべき7つの原則」** — これだけで大半の事故を防げます
2. **`references/teacher_review.md`** — AIに採点を任せる上で最も重要な工程
3. **`references/return_and_appeals.md`** — 返却は事故が起きやすい（実際に2回やらかしています）

## 実測値（参考）

| 項目 | 値 |
|---|---|
| 採点エージェント | 22体 × 6枚（132答案・25小問）、約7分/バッチ |
| AIの合計計算ミス | 1/131件 → **機械検証が必須** |
| 「薄い文字を空欄と誤判定」 | 19件（全ページ1回読み方式のとき）→ **大問クロップ＋拡大が必須** |
| 教員目視で AI判読が覆った率 | 13件中4件（約3割）→ **教員確認工程が必須** |
| 学生のプロンプトインジェクション試行 | 8件超（指示書の対策で全て無視された） |
