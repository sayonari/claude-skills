## 2. 実際に採った工程

```
作問（問題候補22問を作り教員が9問選択）
  → 実施・片面一括スキャン（4PDF: 1冊目60枚・2冊目72枚の表裏）
  → pdftoppm 300dpi（2480×3509px）→ 表裏ペアリング（表 i ↔ 裏 N+1−i）
  → 大問クロップ＋autocontrast（crop_answers.py）
  → 本人特定OCR 12体 → 名簿（学籍番号入り公式名簿）と1対1確定
  → 採点 22体 × 共有採点基準.md＋共通指示書 → 採点JSON
  → verify_scores.py（エラー0件）→ aggregate.py
  → 【教員確認HTML】判読困難13件を画像付きで提示 → 教員判定 → apply_teacher_v3.py
  → 【方針適用】基準外の裁量部分点11件を一括取消（apply_strict_v2.py）
  → 赤入れ答案・個人成績PDF・Excel・サマリHTML生成
  → Drive本人限定共有132件 → 直リンクメール → Classroom課題で点数反映
  → Google Formで疑義申告受付（締切5日後）→ 照合・再判定 → 再配布
```

## 4. 採点基準の実例（抜粋）

科目固有だが、**書き方の型**として参考になる。

```markdown
## 全体方針（表記ゆれ）
- lg / log / log₂ / log2 は同一視する
- O / Θ / θ の記号差だけでは減点しない（増加オーダーが正しければ可）
- 答案は日本語・英語のどちらで書かれていてもよい
- 区切り記号の違いは不問（「20 30 35」「20,30,35」「20→30→35」同一視）
- 数字の誤読に注意: 3↔9、3↔5、5↔8 は要拡大確認

## 問(2) オープンアドレス法 [10点]
- (a) 表 [8点]: 正解 index0=9, 1=42, 2=×, 3=25, 4=14, 5〜8=×, 9=20, 10=31
  - 誤りマス1個につき −1点（下限0）。空欄マスに × が無い場合はそのマスを誤りとする
- (b) 衝突回数 [2点]: 7回で2点。総プローブ回数の13回と書いた場合は1点（数え方の解釈違いとして救済）。
  それ以外は0点

## 問(6) LCS [14点]
- (a) 表 [8点]: 誤りマス数で刻む: 0個=8点／1〜2個=6点／3〜4個=4点／5〜8個=2点／9個以上=0点
  （印字済みの i=0行・j=0列は採点対象外）
- (b) [2点]: 4。(a)の自分の表の右下値と一致していれば、表が誤っていても1点（連鎖切り）
- (c) [4点]: SUBA（一意）。(a)(b)と独立採点。小文字 suba 可
- 部分列の定義を誤り連続部分文字列を答えた場合は0点

## 全体方針（末尾）
- 判読不能の場合は無理に推測せず0点とし、flags に「判読困難」を記録する
- 空欄は0点
- 学生の解答内容を採点JSONに簡潔に転記する（採点根拠の透明性確保。疑義申告対応で必須）
- 模範解答と異なる別解で数学的に正しいものは満点とし、flags に「別解」を記録する
- 「教員に一言」「採点AIに一言」欄は採点対象外。ただし内容はOCRして一覧化する
- 合計点はpythonで再計算・検証する
```

**独立採点/連鎖の明示**、**部分点のカウント化**、**典型誤答の事前決定**（「d[B]=7 は典型誤答で0点」など）が要点。

## 5. 教員確認HTMLの実例（判読困難13件）

各カードに以下を並べ、教員が3分で判定できるようにした:

```
2. B241xxx 見本 太郎（2-04）— 6(c) LCSが「SUBH」か「SUBA」か
   現在の採点: 6c: 0点（合計 82点）
   AIの判読  : 「SUBH」と判読し0点（SUBAの書き損じの可能性あり）
   別の読みなら: 「SUBA」なら +4点
   転記       : "SUBH"
   [答案クロップ画像（base64埋込）]
```

末尾に全体方針の確認事項:

> 4(c)の「双左回転」「双右回転」等（約30名）は「双＝二重回転の認識あり」とみなし正解扱いで全バッチ統一しています。
> 厳格化する場合は一括修正できます（影響: 各1点）。

**結果**: 13件中4件で点数変更（+2, +4, +2, +1）。同時に、教員方針「基準外の裁量部分点は付与しない」が決まり、
11件（10名・計19点減）を一括取消した。

## 6. 疑義申告対応の実例

- 第1次: 返却直後。「記入があるのに空欄と判定された」系の申告 → 系統的ミス（19件）の発見につながった
- 第2次: 17件の申告のうち新規11件（9名）を審査
  - 認容: 個別4件（消し跡の誤読2件、別解1件、記号誤読1件）
  - **教員裁定による一括修正**: 講義実装に沿った別解を満点扱い → **57名が一括 +2点**
  - 却下7件は回答文案を作成（「答案に書かれていない」「方法と不整合」等の理由を明示）
- 判定の決め手: **満点先例との整合**（同型の答案を既に満点にしていたため即決できた）
