# 国際会議×透析 渡航調整スキル（Claude 用）

維持血液透析を受けながら学会出張する研究者（以下「ユーザー」）の出張・渡航計画の**判断手順（アルゴリズム）**をまとめた汎用スキル。

**設計原則（4層構造）**：本ファイルは「データをどう使って考えるか」だけを書く。
- 個人の現在値（透析条件・処方・保有ステータス等）→ `~/.claude/profiles/DIALYSIS_PROFILE.md`・`LOYALTY_PROFILE.md`（**毎回最初に読む**）
- 長期戦略（Amex・ステータスマッチ等）→ `work/_個人/Amex_Loyalty戦略/`
- 個別案件（旅程・ToDo）→ 各旅行プロジェクト（`work/_事務処理/<会議名>参加/` 等）

**適用実績**：東南アジア・豪州・欧州の国際会議および国内学会への出張，計6件以上で運用

---

## 0. 大原則

1. **透析予定が旅程の中心的制約**。「宿→観光→あとで透析」の順では考えない。まず**フライト・学会・透析**の固定条件を置き，その周囲に宿・食事・ラウンジ・特典を配置する
2. **旅行透析は1回5時間を基本とする**。「旅行だから4時間でよい」と安易に短縮しない。可能なら Online-HDF
3. **透析間隔は中2日まで**。中3日以上を作らない。**さらに中2日を2回連続させない**（詳細は §2-A「透析間隔の不変ルール」。ここは毎回必ず検算する）
4. 学会予定と透析予定は別々に計画せず**必ず統合**する。最終成果物は「日付・時間を軸に統合された全予定＋ToDo」
5. 提示物は HTML で作成し `open` で表示する（全プロジェクト共通ルール）
6. 予約・支払い・医療機関への連絡など**外部への実行は必ずユーザーの確認を取ってから**。Claude は調査・比較・下書き・スケジュール設計まで
7. 不確実な情報は推測で埋めず「分からない」と明示。変動値（DW・処方・残高等）は使用前に本人確認
8. 長期案件のタスクは **Confirmed / Pending / ToDo / Waiting / Completed** の状態を付けて管理する

## 1. 最初にやること：正本の取得

0. **`work/_事務処理/透析管理/透析カレンダー.md` を読む（⚠️ 最優先・全出張横断の唯一の正本）**。確定・仮・打診中の全セッションがここに載っている。**各プロジェクトの KNOWLEDGE.md / TODO.md / HTML に書かれた日付は写しであり，古い可能性がある。日付の根拠にしてはならない**。両者が食い違っていたら勝手にどちらかを選ばず，ユーザーに確認する
1. `~/.claude/profiles/DIALYSIS_PROFILE.md` を読む（通常スケジュール・モダリティ・アクセス・DW・希望条件・提出書類・過去実績）
2. `~/.claude/profiles/LOYALTY_PROFILE.md` を読む（カード・ステータス・JAL方針・ラウンジ・eSIM条件）
3. 変動項目は「プロフィールの値＋最終確認日」を提示し，計画確定前にユーザーへ最新値を確認する

## 2-A. 透析間隔の不変ルール（⚠️ 日程に触れるたびに必ず検算する）

日程を提案・変更・記述するときは，**記憶や過去の節の記述に頼らず，毎回この5項目を機械的に検算する**。

1. **中3日以上を作らない**（絶対）
2. **中2日を2回連続させない**（例：金 → 月 → 木）。透析患者にとって負担が大きく危険。海外渡航では「出発前最後の国内透析 → 現地1回目 → 現地2回目」がこの形になりやすいので特に注意する
   - → **そうなる場合は，出発前の土曜に1回追加して受ける**。金・土の連日になるが，**国内なら追加費用はかからず，毒素もよく抜けるのでむしろ望ましい**。海外渡航前に2日連続で受けるのはユーザーがこれまでも実際に行ってきた方法（2026-09-04 ユーザー指摘）
3. **金曜夜のオーバーナイト枠は「飛ばす」以外に「土曜の朝〜日中にずらして受ける」選択肢がある**（2026-09-04 ユーザー指摘）。帰国便が金曜夜に間に合わない・現地透析と連日になる等の場合，**飛ばす判断をする前に必ず「土曜にずらせないか」を検討し，かかりつけ病院に相談する**。「飛ばすと中3日になるから不可」と結論づけてはならない
4. **現地の最終透析を「朝枠」にすると帰国後の金曜夜の通常透析との間隔が確保できる**。例：木曜 07:00-12:00 の現地透析 → 金曜 22:00 開始のかかりつけ病院＝約34時間あくので連日扱いにならず問題ない。会期（学会本会議）と透析を重ねないために現地を月・木に置く設計は，この朝枠とセットで初めて成立する
5. **必ず「透析間隔検算表」を出力してから結論を述べる**。頭の中で済ませない。手で書かず，**必ず次のスクリプトを実行する**：

```bash
python3 ~/.claude/skills/dialysis_conference_travel/scripts/check_intervals.py \
        ~/_data/work/_事務処理/透析管理/透析カレンダー.md
```

   - 入力＝`work/_事務処理/透析管理/透析カレンダー.md`（全出張横断の唯一の正本）
   - 出力＝全セッションの時系列表（中N日・実時間）と，`✗中3日以上` / `⚠中2日2連続` の自動判定
   - **日程を提案・変更・記述する前に必ず実行する**。実行せずに間隔について述べてはならない
   - 日程が変わったら**まず正本カレンダーを直し，変更履歴に理由を書き，再実行する**（プロジェクト側のファイルを先に直さない）
   - 出張がプロジェクトをまたいでも1本の表で見えるので，例えば「海外会議A 10/22 → かかりつけ 10/23 → 国内会議B 10/26」のような**プロジェクト横断の間隔も検出できる**

| 日付・曜日 | 場所 | 開始-終了 | 前回からの間隔 | 判定 |
|---|---|---|---|---|
| 例：10/16(金) | かかりつけ病院 | 13:00-18:00 | — | — |
| 例：10/19(月) | 現地 | 07:00-12:00 | 中2日 | ⚠️ 次も中2日なら 2-A-2 に抵触 |

## 2. 渡航計画の設計手順

1. **会期・会場を確定**（公式サイト＋研究室 Slack。チャンネル名は会議名，canvas に TODO があることが多い）
2. **透析カレンダーを引く**：
   - 出発前最後の通常透析／旅行期間／帰国後最初の通常透析を書き出す
   - 現地で必要な透析回数と，医学的・日程的に適切な日を決める（**§2-A の検算表を必ず作る**。中3日以上を作らない／中2日を2連続させない）
   - **オーバーナイト透析（夜間開始）の場合の含意**：帰国日の朝〜日中に帰着できれば当日夜の通常スロットへそのまま復帰できる／週末を挟む出発では「金曜夜の透析→日曜出発→月曜現地透析」が基本形／日本の病院は日曜休みなので月曜分の前倒しは不可
3. **現地の時間帯を学会と統合して選ぶ**：現実に取れるのは**日中枠だけ**なので，**朝枠（早朝〜昼過ぎまでの5時間）を第一希望**に置く。「午前枠＝4時間」の施設が多いので，**5時間確保できるか（例 08:00-13:00 / 08:30-13:30）を必ず確認**する。単に空いている枠にしない
   - ⚠️ **臨時透析・旅行透析でオーバーナイト（夜間開始）枠は原則取れない**（2026-09-04 ユーザー指摘・再掲）。**施設サイトに「オーバーナイト 月水金」等と書かれていても，それは常時通院する自院患者向けのサービス**であり，外部からの臨時患者は日中枠しか受けられないのが通例。**オーバーナイト前提の旅程を組んではならない**。打診の際に「可能なら」と一言添えて聞くのは構わないが，**あくまで日中5時間枠を本命として設計する**
4. **施設候補を検索**し，各候補について確認する。**評価の第1条件は「英語（または日本語）が通じること」**（2026-09-07 ユーザー指摘）：
   - **① 言語（最優先）**：**英語のウェブページがあるか／英語のメールに英語で返信が来るか**。現地語しか通じない施設は，**透析中に体調の変化を伝えられず，急変時に説明もできないため危険**。会場からの近さより優先する。打診を現地語・英語の併記で送れば，**返信がどちらの言語で来るかがそのまま英語対応のテストになる**
   - ② **5時間可否**（午前枠が4時間の施設が多い。「4時間しかできないならはっきり言ってほしい」と書くと明確な回答が得られる）
   - ③ Online-HDF 可否／時間帯（朝枠）／料金と支払方法／必要書類と提出期限
   - ④ **非居住者・自費患者を受け入れるか**（欧州は公的保険との協定が前提の施設が多く，EHIC を持たない日本人は別扱いになる。打診の冒頭で「非EU・保険カードなし・全額自費」と明示しないと話が進まない）
   - ⑤ 予約方法（**必ず病院へ直接**。代理店は禁止，**面識のある第三者に取り次ぎを頼むのも禁止**）／宿・会場からの移動時間（週2回通うので近さが効くが，①②より下）
5. **フライト選定**：研究室の同一便方針があれば従う。深夜発帰国便は「最終日フル参加→翌朝帰国→当日夜に日本の通常スロット復帰」が組めるので相性が良い。JAL中心方針・ラウンジ（§6）も考慮
6. **宿選定**：§5 の基準
7. **大学手続き**：§7 のリスト
8. 全体案を **HTML で提示**し，ユーザーの判断（病院・宿・便の最終決定）を仰ぐ

## 3. 旅行透析の手配

### 手配ルート
1. **病院へ直接予約・直接メール連絡のみ**（日本語フォームがある病院もある。例：バンコクのサミティベート病院。フォームが無ければ英文メールで直接打診。テンプレは DIALYSIS_PROFILE.md）
2. **旅行透析代理店（メディカルデスク等）は絶対利用禁止**（2026-08-25 ユーザー指示。手数料が高額で，これまで一貫して病院と直接やり取りして手配してきた。代理店経由でしか案内されない病院でも，まず病院へ直接連絡を試みること）

### 打診は「波」に分けて出す（⚠️ 一度に広げすぎない）

- **第一波は3件まで**。会場からの近さ・受入実績・条件の合致で上位3件を選ぶ
- **1週間返事がなければ第二波**（次の3件）。不達が判明した分は即座に補充してよい
- **理由**：①断りの連絡が増えて手間になる ②同じ県内・同じ市内の透析施設は横のつながりがあり，複数から同時に同じ問い合わせが届くのは印象が悪い ③返信を比較する作業自体が重くなる
- ただし**リードタイムを切っている場合（海外で3ヶ月を割っている等）は例外**で，最初から広く出してよい。その場合は本文に「複数の施設に同時に問い合わせている」と正直に書く
- 実例：ある欧州会議で7件へ同時送信し，「多すぎる」と指摘を受けた。別の東南アジア会議では第一波3件→第二波→第三波と広げて適切だった

### 予約のリードタイム（⚠️ 最重要。国内と海外で全く違う）

| 区分 | 予約（打診・枠確保）を始める時期 | 補足 |
|---|---|---|
| **国内の臨時透析** | **1ヶ月前 〜 2週間前** | 早すぎても受け付けてもらえない。逆に直前は満床リスク（直前打診で確保できなかった例あり） |
| **海外の旅行透析** | **3ヶ月前** | **1ヶ月前では間に合わない／受けてもらえない可能性が大きい**。書類審査・スクリーニング・枠確保に時間がかかるため |

（2026-09-04 ユーザー指摘）

- **プロジェクト立ち上げ時に「打診開始日」を逆算して ToDo に置く**：海外は会期の3ヶ月前，国内は1ヶ月前。会議への参加を決めた時点で海外分は即着手と考えてよい
- 海外で3ヶ月前を切っている場合は、**参加可否そのものが危うい**と判断し，ユーザーへ早期に報告する（実際に透析を確保できず出張中止になった例がある）
- 国内分を早く動かしすぎない：「今の時期に予約を入れるのは早すぎる」と断られる。会期の1ヶ月前を目安に着手する

### 必要書類（詳細リストは DIALYSIS_PROFILE.md）
- 感染症スクリーニング・血液検査・直近3回の透析記録・medical summary・dialysis prescription が定番
- **書類の提出は概ね1ヶ月前まで**（＝打診はさらに前。上記リードタイム表を参照）。「施設が見つかったら終わり」ではなく，**打診と同時に必要書類・提出期限を確認**する
- 英文書類は主治医に依頼（取得2〜3週間みる）。既存の署名済セットがあれば日付更新版の依頼で済むことが多い

### 費用まわり
- ⚠️ **透析費は研究費（科研費・寄付金・基盤経費のいずれも）から支出できない。全額が本人の自費**（2026-09-04 ユーザー指摘）。**出張予算の集計に透析費を含めてはならない**。費用表では「研究費で支出する額（登録・交通・宿・ビザ/健診）」と「透析費（自費）」を必ず別枠にし，予算残高の計算には前者だけを使う
- 海外透析の目安：東南アジア 2.5万〜4.5万円/回，豪州 AUD 900〜1,000/回。領収書・診療内容明細を必ず受領し，共済組合の**海外療養費支給申請**を検討（自己負担の圧縮になる）
- 決済カードの通用性に注意（AMEX が弾かれるサイトあり→VISA を予備に）

## 4. 参加日程の設計

- 「本会議は全部出る」が基本方針。日中に透析を入れざるを得ない場合は，プログラム公開後に**自研究室の発表・座長・重要セッションと重ならない**時間帯を選ぶ
- チュートリアル日・ワークショップ日は本会議と扱いを分けてユーザーに確認
- プログラム公開が遅い会議では，病院枠の仮押さえを先に行い，確定後に微調整

## 5. 宿の選定基準

1. **価格帯**：学会出張向け。大学の宿泊費規程・概算払の範囲を意識
2. **保有ステータスとの照合**（LOYALTY_PROFILE.md 参照）：Marriott/Hilton/Radisson/BW 等の対象ホテルが候補にあれば特典欄（朝食・アップグレード・レイトチェックアウト）を比較表に設ける。Hilton Gold は朝食無料が大きい
3. **位置**：会場への近さ × 透析病院への近さのバランス。夕方透析なら病院側に寄せる価値が上がる。深夜便利用日は空港側1泊の折衷案も検討
4. **研究室の動き**：同宿・近宿を推奨する事務方針が多い → Slack で他メンバーの宿を確認してから提案

## 6. 付帯要素（毎回チェックリスト化する）

- **ラウンジ**：Priority Pass（Amexプラチナ付帯）で使える現地空港ラウンジ／羽田T3なら Centurion Lounge。深夜便前の待機に価値
- **eSIM**：7日程度・データ無制限・数千円が条件。日本回線（SMS/2FA用）を海外で止めてよいかの確認も毎回必要
- **食事**：Amexダイニング特典・ホテル特典の現地適用可否（「日本発行プラチナで使えるか」を必ず確認）
- **海外旅行保険**：カード付帯の利用付帯条件を確認。慢性疾患（透析）は保険対象外＝透析費は自費前提
- **ビザ**：渡航先により要否確認。透析患者は健康診断を要求される国がある（豪州 Visitor visa で実績）→ 早めに着手

## 7. 大学の出張手続き（豊橋技科大）

- **概算払**：海外は概算払推奨。事務の指示する期日までに旅程確定（目安：出発1ヶ月以上前）
- **出張フォーム**（事務の Google フォーム）：旅程確定後に入力。「用務」を忘れない。「予算」は指示がなければ空欄
- **海外渡航届**（Web・出発1週間前まで）：渡航届・旅程・海外旅行保険証券コピー・誓約書・たびレジ登録コピー・ビザコピー／**海外渡航書**も Web で1週間前まで
- 出張書類（旅行依頼伺・出張報告書）に押印（提出先：秘書）
- **出張中の保管物**（ジップロック）：搭乗券半券・参加章・会場写真
- **出張後**：半券・エビデンス・参加費立替払の押印（食事回数を伝える）。円建てでない領収書はカード明細も必要 → 立替払い明細提出プロジェクトと連携

## 8. プロジェクト運用

- 出張・学会参加は 1 件 = 1 プロジェクト（`work/_事務処理/<会議名>参加/` 等）で管理し，`/make_project` で立ち上げる
- Drive 正本：`マイドライブ/nishimura/project/_InternationalConference/<YYYYMMDD>_<会議名>_<都市>/`（出張事務書類の正本は `document/大学関連/出張書類/<年度>/` 側の場合もある。既存フォルダを確認）
- 新しい知見（施設・手続き変更・決済の癖など）が出たら：**汎用的な判断手順→本ファイルに追記／個人の現在値→ DIALYSIS_PROFILE.md / LOYALTY_PROFILE.md を更新（旧値はHistoryへ）**／案件固有の事実→プロジェクトの KNOWLEDGE.md
